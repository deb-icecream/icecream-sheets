## Fix (implemented)
Preference order from the brief: (1) direct signed path — already the production pattern and already bypasses the proxy (signed mode unaffected, nothing to do); (2) make the proxy timeout sufficient for checkpoint-class ops — CHOSEN, as the smallest correct change the architecture supports; (3) streaming/chunking — not needed where the response is a single completion signal (release/rehydrate/ops).
- `packages/gateway/src/gateway.ts`: new exported `ENGINE_UPSTREAM_TIMEOUT_MS = 600_000`. The proxy timeout selection is now route-class based: `routePrefix === '/api/engine'` → 600 s for EVERY engine route; agent/message keeps 270 s; all other (stateless) routes keep the 30 s fail-fast default. The previous per-route carve-out list (isEngineFileLoad/isEngineSnapshot/isEngineDownload/isEngineLibrary/isEngineRead) was removed — each carve-out had been added only after a gate failure, and the list is what allowed the checkpoint-class routes to be missed. Body caps are UNCHANGED (256 MB load, 32 MB extras-carrying save routes, 1 MB default).
- `packages/gateway/src/index.ts`: exports ENGINE_UPSTREAM_TIMEOUT_MS.
- `packages/gateway/src/services/engineSvc.ts`: comment-only update (BUILD_WAIT_TIMEOUT_MS comment now names ENGINE_UPSTREAM_TIMEOUT_MS).
- Design grounding: deployment-architecture.md — proxied engine traffic is 600 s-class service work; engine request timeout is the long class (worst ops P99 build ~249 s, P95 save ~109 s < 600 s); gateway server requestTimeout 660 s (bin/gateway.ts) already sits above the 600 s class, and the engine bin's own requestTimeout is likewise 660 s for the direct path.
- Regression test: `packages/gateway/tests/gatewayEngineTimeout.test.ts` (6 tests, pattern mirrors the D4 agent-message test in agentBinding.test.ts): constant pinned at 600_000; /session/release, /load/storage-ref, /ops, /session/rehydrate each survive a 32 s parked upstream through the gateway (200); control: /api/echo/* still 502s at ~30 s.
- tsc: `npx tsc -p tsconfig.json --noEmit` in packages/gateway → clean (exit 0).
